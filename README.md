## Emulation & Retro Gaming (Open Source contributions)

- [RetroAchievements](https://retroachievements.org/): adding achievements to retro games
  - Built achievement sets by reverse engineering game memory ([my sets](https://retroachievements.org/user/meleu/developer/sets))
  - [RAWeb](https://github.com/RetroAchievements/RAWeb/commits/master?author=meleu): website backend
  - [RADocs](https://docs.retroachievements.org/): official documentation (founder)
  - [RANews](https://github.com/RetroAchievements/RANews/commits/master?author=meleu): monthly webzine
- [RetroArch](https://github.com/libretro/RetroArch/commits/master?author=meleu): RetroAchievements integration in the libretro multi-emulator frontend (C)
- [RetroPie](https://github.com/RetroPie/RetroPie-Setup/commits/master?author=meleu): configuration tooling (Bash/Python) for turning a Raspberry Pi into a retro gaming station
